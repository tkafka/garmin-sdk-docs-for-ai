## Overview

:::: docstring
::: discussion
The Position.Info class contains all of the information provided by the
positioning system.

Position Info can be retrieved on every call of
[onUpdate()](../../Toybox/WatchUi/View.html#onUpdate-instance_function)
or it can be obtained on demand. Fields in this class may return `null`
so should be checked for `null` values prior to use.
:::

### var accuracy as [[Position.Quality](../../Toybox/Position.html#Quality-module)]{.type} {#accuracy-var .signature}

:::: docstring
::: discussion
The positional accuracy.

This is given as one of the following values: good, usable, poor, or not
available, which corresponds with the Position.QUALITY\_\* constants.
This cannot be `null`.

### var position as [[Position.Location](../../Toybox/Position/Location.html)]{.type} or **Null** {#position-var .signature}

:::: docstring
::: discussion
The latitude and longitude of the position.

If no GPS is available or is between GPS fix intervals (typically 1
second), the position is propagated (i.e. dead-reckoned) using the last
known heading and last known speed. After a short period of time, the
position will cease to be propagated to avoid excessive accumulation of
position errors.
:::
