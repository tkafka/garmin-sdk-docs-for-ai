# Module: Toybox.Cryptography

## Overview

:::: docstring
::: discussion
The Cryptography Module will allow the application to create a
[Cipher](../Toybox/Cryptography/Cipher.html) object that can encrypt and
decrypt [ByteArray](../Toybox/Lang/ByteArray.html) objects.

MODE_ECB

0

API Level 3.0.0

Electronic Code Book (ECB)

This is the simplest encryption mode. Each plaintext block is directly
encrypted into a ciphertext block, independent of any other block. This
mode exposes frequency of symbols in your plaintext. Other modes (e.g.
CBC) are recommended.

::: inline
<https://en.wikipedia.org/wiki/Block_cipher_mode_of_operation#Electronic_Codebook_(ECB)>
:::

MODE_CBC

1

API Level 3.0.0

Cipher-Block Chaining

Each ciphertext block depends on the current and all previous plaintext
blocks. An Initialization Vector (IV) is required. The IV is a data
block to be transmitted to the receiver. The IV can be made public, but
it must be authenticated by the receiver and it should be picked
randomly.

::: inline
<https://en.wikipedia.org/wiki/Block_cipher_mode_of_operation#Cipher_Block_Chaining_(CBC)>

### **createPublicKey(algorithm as [[Cryptography.HashAlgorithm](../Toybox/Cryptography.html#HashAlgorithm-module)]{.type}, bytes as [[Lang.ByteArray](../Toybox/Lang/ByteArray.html)]{.type})** [ as [[Cryptography.Key](../Toybox/Cryptography/Key.html)]{.type}]{.type} {#createPublicKey-instance_function .signature}

:::: docstring
::: discussion
Create a public [Key](../Toybox/Cryptography/Key.html) object from bytes
to be added to a
[KeyAgreement](../Toybox/Cryptography/KeyAgreement.html).

If a public key is received from another party, it can be converted to a
[Key](../Toybox/Cryptography/Key.html) object using this method.
:::
::::

:::: note
::: inline
[Note:]{.noteTitle}

bytes is expected to be in little-endian byte order.
:::
