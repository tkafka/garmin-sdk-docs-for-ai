## Overview

:::: docstring
::: discussion
A representation of an animation resource.

AnimationResource objects are returned by the
[loadResource()](../../Toybox/WatchUi.html#loadResource-instance_function)
method.

### **toString()** [ as [[Lang.String](../../Toybox/Lang/String.html)]{.type}]{.type} {#toString-instance_function .signature}

:::: docstring
::: discussion
Get info about an animation resource as a String.

The info String is formatted as \"Animation X x Y\" where \"X\" is the
width of the animation and \"Y\" is the height.
