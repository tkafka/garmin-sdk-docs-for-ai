## Overview

:::: docstring
::: discussion
The WorkoutStepInfo class contains information about the current
workout.

This information can be retrieved with the
[getCurrentWorkoutStep()](../../Toybox/Activity.html#getCurrentWorkoutStep-instance_function)
or
[getNextWorkoutStep()](../../Toybox/Activity.html#getNextWorkoutStep-instance_function)
methods.
:::
