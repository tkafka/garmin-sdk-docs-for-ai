# Module: Toybox.BluetoothLowEnergy

## Overview

:::: docstring
::: discussion
The BluetoothLowEnergy module provides access to Generic BLE
communication functionality in the central role. Including the ability
to scan for peripheral devices, pair with sensors, and performing GATTC
operations on a peripheral

### **pairDevice(scanResult as [[BluetoothLowEnergy.ScanResult](../Toybox/BluetoothLowEnergy/ScanResult.html)]{.type})** [ as [[BluetoothLowEnergy.Device](../Toybox/BluetoothLowEnergy/Device.html)]{.type} or **Null**]{.type} {#pairDevice-instance_function .signature}

:::: docstring
::: discussion
Pairs a peripheral device seen in scanning with the system.

The BLE Subsystem will begin to search for the device specified by the
scanResult parameter. Once the device is found and connected,
[onConnectedStateChanged()](../Toybox/BluetoothLowEnergy/BleDelegate.html#onConnectedStateChanged-instance_function)
will be called on the registered
[BleDelegate](../Toybox/BluetoothLowEnergy/BleDelegate.html) with the
associated [Device](../Toybox/BluetoothLowEnergy/Device.html) object

This pairing does not persist across application instances.
:::
::::

:::: tags

-   [scanResult]{.name} ---
    [([[BluetoothLowEnergy.ScanResult](../Toybox/BluetoothLowEnergy/ScanResult.html)]{.type})]{.type}

    ::: inline

    `null`.
    :::

    ---

    ::: inline
    the device that was added to the paired list or `null` if the device

### **registerProfile(profile as { :uuid as [[BluetoothLowEnergy.Uuid](../Toybox/BluetoothLowEnergy/Uuid.html)]{.type}, :characteristics as [[Lang.Array](../Toybox/Lang/Array.html)]{.type}\<{ :uuid as [[BluetoothLowEnergy.Uuid](../Toybox/BluetoothLowEnergy/Uuid.html)]{.type}, :descriptors as [[Lang.Array](../Toybox/Lang/Array.html)]{.type}\<[[BluetoothLowEnergy.Uuid](../Toybox/BluetoothLowEnergy/Uuid.html)]{.type}\> }\> })** [ as **Void**]{.type} {#registerProfile-instance_function .signature}

:::: docstring
::: discussion
Registers a Bluetooth Profile Definition

Call this function to define all of the Profiles that will be used in
the application. Only registered characteristics and descriptors will be
available when performing GATT operations

When the operation is completed,
[onProfileRegister()](../Toybox/BluetoothLowEnergy/BleDelegate.html#onProfileRegister-instance_function)
will be called on the registered
[BleDelegate](../Toybox/BluetoothLowEnergy/BleDelegate.html) with the
UUID and a Status.

Registration can fail if too many profiles are registered, the current
limit is 3.
:::
::::

::::: tags
Parameters:

-   [profile]{.name} ---
    [([[Lang.Dictionary](../Toybox/Lang/Dictionary.html)]{.type})]{.type}
    ---

    ::: inline
    Profile Definition. Defines the expected Profile UUID, Profile
    Characteristics and Characteristic Descriptors. Cannot be `null`.
    :::

::: examples
Example:

``` {.example .code}
using Toybox.BluetoothLowEnergy;

   function registerProfiles() {
       var profile = {                                                  // Set the Profile
           :uuid => Ble.stringToUuid("xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"),
           :characteristics => [ {                                      // Define the characteristics
                   :uuid => Ble.stringToUuid("xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"),     // UUID of the first characteristic
                   :descriptors => [                                    // Descriptors of the characteristic
                       Ble.stringToUuid("xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"),
                       Ble.stringToUuid("xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx") ] }, {
                   :uuid => Ble.stringToUuid("xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx") }]   // UUID of the second characteristic
       };

       // Make the registerProfile call
       BluetoothLowEnergy.registerProfile( profile );
  }
```
:::

Since:

::: since
API Level 3.1.0
:::

Throws:

-   [([[BluetoothLowEnergy.ProfileRegistrationException](../Toybox/BluetoothLowEnergy/ProfileRegistrationException.html)]{.type})]{.type}
    ---

    ::: inline
    If registration could not be completed
    :::

### **setDelegate(delegate as [[BluetoothLowEnergy.BleDelegate](../Toybox/BluetoothLowEnergy/BleDelegate.html)]{.type})** [ as **Void**]{.type} {#setDelegate-instance_function .signature}

:::: docstring
::: discussion
Sets the Delegate Handler for Bluetooth Asynchronous Callbacks

An application can only have 1 registered delegate. Subsequent calls to
this function will override the current delegate
:::
::::

::::: tags
Parameters:

-   [delegate]{.name} ---
    [([[BluetoothLowEnergy.BleDelegate](../Toybox/BluetoothLowEnergy/BleDelegate.html)]{.type})]{.type}
    ---

    ::: inline
    An implementation of the
    [BleDelegate](../Toybox/BluetoothLowEnergy/BleDelegate.html) class
    to register as the handler for callbacks, or `null` to deregister
    the current handler.
    :::

::: examples
Example:

``` {.example .code}
using Toybox.BluetoothLowEnergy as Ble;
class Handler extends Ble.BleDelegate {
    function initialize() {
        BleDelegate.initialize();
    }
}

var handler = new Handler();
Ble.setDelegate(handler);
```
