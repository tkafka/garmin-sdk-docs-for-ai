### **initialize(options as { :algorithm as [[Cryptography.KeyPairAlgorithm](../../Toybox/Cryptography.html#KeyPairAlgorithm-module)]{.type}, :privateKey as [[Lang.ByteArray](../../Toybox/Lang/ByteArray.html)]{.type} })** {#initialize-instance_function .signature}

:::: docstring
::: discussion
Constructor

A KeyPair can be initialized from a private key by passing a private key
[ByteArray](../../Toybox/Lang/ByteArray.html) from an initialized
[Key](../../Toybox/Cryptography/Key.html) object into the `:privateKey`
option of the initialize method for this class. If no private key is
provided, then both a private and public key will be generated using the
required `:algorithm` option.
:::
::::

:::: note
::: inline
[Note:]{.noteTitle}

privateKey is expected to be in little-endian byte order.
:::
